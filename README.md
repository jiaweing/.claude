## Important
- Always use the todos tool to track tasks
- Never use em dashes, always write it so that they don't need it. For cases like lists, you can use - or :
- Never use a : after an inline `code`, use a - instead if you need

## Imports
Do not import what you need to use first because the Biome linter will remove it after you save. So always implement before importing.

## Environment
Always use bun.

## Secrets
Never put any secrets in the chat.

## Verification
Always check your work after implementation. Never complete without verifying your work was successfully implemented. Use either
- the built-in computer use
- agent browser by Vercel
- playwright
- maestro (for mobile apps)
